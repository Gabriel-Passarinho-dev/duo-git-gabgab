- O que causou o conflito?
Um conflito entre o git push, causado por conta da pessoa A ter feito uma edição e um push e depois a pessoa B ter tentado fazer um push sem ter um pull da nova versão.

- Como vocês decidiram qual versão manter?
Decidimos manter as duas no mesmo arquivo.

- Em um projeto real, o que vocês fariam para evitar conflitos?
Anuciar que estamos fazendo mudanças no projeto e quando fizermos o push para que todos saibam que podem fazer um pull da versão nova.
